## Surprises & Discoveries

Мобильная сетка operations размещает заголовок как отдельную колонку. Минимальные ширины истории не учитывают боковое меню. Поле товарной группы содержит несколько интерактивных элементов в одном label. Родительский Git показывает весь проект как untracked, поэтому проверка изменений требует отдельного исходного снимка файлов.
