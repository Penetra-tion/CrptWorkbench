## Purpose / Big Picture

Оператор вводит номер сертификата, декларации или СГР в одной форме и получает карточку с данными официального реестра. Результат остаётся в истории выбранного профиля. Mock позволяет проверить сценарий локально; Production использует только подтверждённые публичные поисковые интерфейсы.

## Surprises & Discoveries

- У проекта собственный Git-репозиторий внутри родительского; исходная памятка об этом устарела. `git rev-parse --show-toplevel` указывает на `СZHELPER`.
- Официальный API `https://nsi.eaeunion.org/api/v1/dictionaries/1995/elements` доступен без авторизации. Фильтр `conditions[0].conditionType=like`, `conditions[0].code=NUMB_DOC`, `conditions[0].value=<номер>` вернул JSON с массивом `elements` и данными СГР. После серверного фильтра требуется точное сравнение номера.
- В официальном описании СГР отдельно отмечены кириллическая и латинская `Е` в номере. Их следует проверять как варианты поискового запроса и возвращать только совпадение по утверждённой нормализации.
- Опубликованная конфигурация реестра ЕАЭС указывает `POST https://tech.eaeunion.org/spd/find` с коллекцией `kbdallread.service-prop-35_1-conformityDocDetailsType`; запрос по `docId` вернул структурированный ответ с типом, страной, датами, участниками, продукцией и кодом статуса. Открытый интерфейс также содержит российские записи. Программный контракт Росаккредитации для деклараций пока не подтверждён.
- Публичный фильтр `unifiedCountryCode.value` вернул записи RU, BY, KZ, AM, KG; это подтверждает охват пяти стран единой коллекцией. Пользователь отдельно разрешил применять этот же API для российских сертификатов и деклараций.
- Браузерный инструмент доступен только для встроенного браузера без настройки ширины окна; попытка открыть вспомогательную страницу для узкого viewport заблокирована политикой URL браузера. Повторять обходным способом нельзя. Узкоэкранная проверка остаётся незавершённой.

## Decision Log

- Decision: Неподтверждённый Production-маршрут не подключать. Rationale: Открытая страница не доказывает контракт программного доступа. Date/Author: 2026-09-29, Codex.
- Decision: Один номер может породить два поисковых маршрута для иностранного сертификата/декларации. Rationale: Форматы в пользовательском PDF совпадают. Date/Author: 2026-09-29, Codex.
- Decision: Код статуса ЕАЭС показывать без неподтверждённой расшифровки и со ссылкой на карточку реестра. Rationale: API отдаёт код, а опубликованное соответствие человекочитаемым статусам не подтверждено. Date/Author: 2026-09-29, Codex.
- Decision: Использовать единый публичный реестр ЕАЭС для сертификатов и деклараций всех пяти стран, включая RU. Rationale: программный поиск Росаккредитации не подтверждён, а пользователь явно одобрил замену. Date/Author: 2026-09-29, Codex.
- Decision: Принять инспекцию CSS как замену узкоэкранной браузерной проверки. Rationale: браузерный инструмент запретил вспомогательную страницу и не предоставляет управление viewport; пользователь явно разрешил замену. Date/Author: 2026-09-29, Codex.

## Validation and Acceptance

В Mock российский сертификат, декларация, иностранный номер и СГР дают соответствующие карточки. Неверный номер не запускает поиск. Для неоднозначного номера проверяются два источника; отсутствие подтверждается только когда все необходимые источники ответили. Ошибка источника даёт «Не удалось проверить» и ссылку. СГР в Production возвращает структурированную карточку из официального API. Неизвестный формат ответа не считается пустой выдачей. История видна только активному профилю, технический ответ маскируется. Финал — ноль ошибок сборки, полный набор тестов и UI-проверки.

## Idempotence and Recovery

Схему базы не менять. Повторный поиск безопасен и не создаёт внешних документов. При изменении внешнего контракта возвращать ошибку проверки, не подменяя её отсутствием записи. Если любой требуемый источник не подтверждён, не объявлять поддержку всех стран завершённой и не выполнять выключение компьютера.
